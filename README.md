<br/>
Benchmarked identical Transformer decoder blocks &amp; ResNet50 across <b>PyTorch</b>, <b>TensorFlow</b>, and <b>JAX</b> on NVIDIA GPUs and Google TPUs to evaluate compiler-level gains over eager execution:
<ul>
  <li><code>torch.compile + Triton</code> — 2–3× inference/training speedup over eager PyTorch</li>
  <li><code>PyTorch + TensorRT (FP16)</code> — Major deployment throughput &amp; GPU-count reduction</li>
  <li><code>JAX / Flax + jit (XLA)</code> vs. <code>PyTorch/XLA</code> on TPUs &amp; <code>tf.function</code> graph capture</li>
</ul>
